# 🏏 IPL Live Bot

A real-time IPL cricket live score monitoring bot that fetches live match data and delivers automated notifications via Telegram.

---

## 📌 Overview

This bot scrapes live IPL 2026 match data, processes score updates, and pushes real-time notifications to a Telegram channel or group. Built for cricket fans and automation enthusiasts.

---

## 🛠️ Tech Stack

- **Language:** Python 3
- **Libraries:** Requests, BeautifulSoup, python-telegram-bot
- **Deployment:** Runs as a background process / cron job

---

## ⚙️ Features

- 🔴 Real-time live score scraping
- 📲 Telegram bot notifications
- 📊 Match dashboard generation
- ⚡ Auto-updates at configurable intervals
- 🔁 Baseline loading for incremental score diffs

---

## 🚀 Setup & Usage

```bash
git clone https://github.com/RCMCA1979/ipl-live-bot.git
cd ipl-live-bot
pip install -r requirements.txt
export BOT_TOKEN="your_telegram_bot_token"
export CHAT_ID="your_chat_id"
python main.py
```
